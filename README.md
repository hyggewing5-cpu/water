# ระบบบันทึกการใช้น้ำปะปา

Web App บน Google Apps Script สำหรับหน่วยงาน ใช้จด ติดตาม จัดเก็บหลักฐาน และสรุปการใช้น้ำปะปา (รายวัน/รายสัปดาห์/รายเดือน)

- **ระบบ 1 – หน้าจดมิเตอร์ (มือถือ):** `…/exec` สแกนเลขจากรูปหรือพิมพ์เอง เก็บรูปหลักฐานใน Google Drive
- **ระบบ 2 – หลังบ้าน:** `…/exec?page=admin` ต้อง Log in มีแดชบอร์ด รายงาน ส่งออก CSV/PDF จัดการผู้ใช้และมิเตอร์
- **แจ้งเตือนผิดปกติ:** อีเมล และกลุ่ม Telegram พร้อมสรุปประจำวันช่วง 17:00-18:00 น.

> GitHub ใช้เก็บและควบคุมเวอร์ชันของโค้ดเท่านั้น ตัวเว็บแอปทำงานบน Google Apps Script (GitHub Pages รันโค้ดฝั่งเซิร์ฟเวอร์แบบนี้ไม่ได้)

## โครงสร้างโปรเจ็กต์

```
src/
  Code.gs          โค้ดฝั่งเซิร์ฟเวอร์ (ข้อมูล, ล็อกอิน, รายงาน, แจ้งเตือน)
  Index.html       หน้าเว็บทั้ง 2 ระบบ
  appsscript.json  manifest (เวลาไทย, สิทธิ์เว็บแอป)
docs/
  USER_MANUAL.md   คู่มือการใช้งาน
```

## ติดตั้งแบบคัดลอก-วาง

1. สร้าง Google Sheet ใหม่ > ส่วนขยาย > Apps Script
2. วางเนื้อหา `src/Code.gs` ลงใน `Code.gs`
3. สร้างไฟล์ HTML ชื่อ `Index` แล้ววางเนื้อหา `src/Index.html`
4. Project Settings > ตั้ง Time zone เป็น `(GMT+07:00) Bangkok`
5. เลือกฟังก์ชัน `setup` กด Run (อนุญาตสิทธิ์) เพื่อสร้างชีตและโฟลเดอร์รูป
6. Deploy > New deployment > Web app: Execute as **Me**, Who has access **Anyone**
7. ดูรหัสผ่านเริ่มต้นของบัญชี `admin` ในแผง **Execution log (บันทึกการดำเนินการ)** ด้านล่างหลังรัน `setup` (ระบบสุ่มให้ ไม่มีรหัสตายตัว) แล้วเข้าหลังบ้านและ **เปลี่ยนรหัสผ่านทันที**

## ติดตั้งด้วย clasp (ทางเลือก)

```bash
npm i -g @google/clasp
clasp login
cd src
clasp create --type webapp --title "ระบบบันทึกการใช้น้ำปะปา"   # หรือ clasp clone <scriptId>
clasp push
clasp open        # แล้วรัน setup ครั้งแรกและ Deploy ตามขั้นตอนด้านบน
```

## ตั้งค่าเพิ่มเติม (Script Properties)

| ชื่อ | ใช้ทำอะไร | ตั้งที่ไหน |
|---|---|---|
| `GEMINI_API_KEY` | สแกนเลขจากรูป (ขอฟรีที่ aistudio.google.com) | Project Settings > Script Properties |
| `TG_TOKEN`, `TG_CHAT` | แจ้งเตือน Telegram | ตั้งผ่านหลังบ้าน แท็บ "ตั้งค่าแจ้งเตือน" |
| `ALERT_MULT`, `ALERT_MIN`, `ALERT_MISS_DAYS`, `ALERT_EMAILS` | เกณฑ์แจ้งเตือนและอีเมลผู้รับ | ตั้งผ่านหลังบ้านเช่นกัน |

ตั้งเวลาตรวจรายวัน: รันฟังก์ชัน `installDailyTrigger` 1 ครั้ง (ทำงานสุ่มภายในช่วง 17:00-18:00 น.)

## อัปเดตเวอร์ชัน

แก้โค้ดแล้วต้อง Deploy > Manage deployments > แก้ไข > **New version** หน้าเว็บจึงเปลี่ยน ลิงก์เดิมใช้ต่อได้

## ความปลอดภัย

- รหัสผ่านเริ่มต้นของ `admin` ถูกสุ่มตอนรัน `setup` ให้เปลี่ยนทันทีหลังเข้าสู่ระบบครั้งแรก รหัสผ่านเก็บเป็นค่าแฮช SHA-256 พร้อมเกลือคงที่ และล็อกชั่วคราวเมื่อกรอกผิด 5 ครั้ง
- หน้าจดมิเตอร์เปิดให้ทุกคนที่มีลิงก์ใช้ได้ ควรแจกลิงก์เฉพาะผู้จด หรือเปลี่ยนเป็น "เฉพาะบัญชีในองค์กร" ตอน Deploy
- อย่าใส่ Bot Token หรือ API Key ลงในไฟล์โค้ดหรือ commit ขึ้น GitHub ให้เก็บใน Script Properties เท่านั้น
- ไม่ควรเปิด repo เป็น Public ถ้าโค้ดมีข้อมูลเฉพาะของหน่วยงาน

## วิธีนำขึ้น GitHub

```bash
cd water-meter-app
git init && git add . && git commit -m "ระบบบันทึกการใช้น้ำปะปา"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```
หรือสร้าง repo ใหม่บนเว็บ GitHub แล้วกด **Add file > Upload files** ลากทั้งโฟลเดอร์เข้าไป

## ข้อมูลผู้พัฒนา

แสดงที่มุมล่างขวาของทุกหน้า แก้ได้ที่ค่าคงที่ `DEV` ต้นไฟล์ `src/Code.gs` (ชื่อ ตำแหน่ง หมายเลขโทรศัพท์) แล้ว Deploy เป็นเวอร์ชันใหม่ ผู้ที่นำระบบไปใช้ต่อสามารถแก้เป็นข้อมูลของตนเองได้
